# KAIROS Frontend

React, TypeScript, Tailwind CSS, and Vite user interface for the KAIROS v1.0 productivity workflow.

The primary navigation is Dashboard, Tasks, Knowledge, Plan, Focus, Progress, and Settings. Algorithm benchmarks and structure inspection are not part of the normal user interface.

See the repository root [README](../README.md) for setup, feature behavior, API overview, privacy, limitations, and the end-to-end demo.

A scripted browser walk-through of the demo flow is in `e2e/demo-flow.mjs`; the root README explains how to run it against an empty workspace.
